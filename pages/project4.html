AuthGuard
Authentication Microservice

A production-ready authentication microservice with JWT-based access/refresh tokens, OAuth2 social login, Redis session management, and rate limiting — designed to be plug-and-play for any Node.js application.

View Documentation GitHub

Project Overview

AuthGuard is a standalone authentication microservice built with Node.js and Express, designed to handle all authentication and authorization concerns so your main application doesn't have to. It implements industry-best practices for token management, session security, and protection against common attack vectors.

The service can be deployed independently and communicates via a documented REST API, making it compatible with any frontend or backend that speaks HTTP.

Key Features

  • JWT access tokens (15min expiry) + refresh tokens (7-day, stored in Redis)
  • OAuth2 social login via Google, GitHub, and Discord
  • Refresh token rotation — every use issues a new refresh token, invalidating the old one
  • Rate limiting per IP and per user using Redis sliding window algorithm
  • Account lockout after N failed login attempts with email unlock flow
  • Two-factor authentication (TOTP) via Google Authenticator
  • Full audit log of auth events (login, logout, password reset, 2FA toggle)
  • Swagger/OpenAPI documentation auto-generated from route definitions

Challenges Faced

  • Refresh token theft detection — if a stolen refresh token is used after rotation, the service detects the reuse, invalidates the entire token family, and forces re-login. Implementing this family-tracking logic in Redis was complex.
  • Clock skew in distributed environments — JWT validation failures in multi-instance deployments due to server time differences. Added a configurable clock tolerance buffer.
  • TOTP window synchronization — allowing a ±1 window for TOTP codes to account for user clock drift without weakening security.

Future Improvements

  • Passkey / WebAuthn support for passwordless authentication
  • Magic link login via email
  • Admin dashboard UI to manage users and sessions
  • Kubernetes Helm chart for easy cluster deployment
  • Add support for SMS-based OTP via Twilio as a 2FA alternative
  • Publish as an npm package for easy integration
