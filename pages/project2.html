TaskFlow
Collaborative Project Manager

A real-time, collaborative project management tool inspired by Trello and Notion. Featuring Kanban boards, drag-and-drop task cards, team member roles, in-app chat, and detailed analytics.

Live Demo GitHub (Client)

Project Overview

TaskFlow is a full-featured project management platform built to help development teams and creative agencies manage projects efficiently. It combines the visual simplicity of Kanban boards with robust team collaboration features like real-time updates, file attachments, and integrated chat.

The motivation was my own frustration during a university group project — juggling GitHub Issues, WhatsApp messages, and Google Docs was chaotic. TaskFlow brings everything together.

Key Features

  • Drag-and-drop Kanban boards with customizable columns and color labels
  • Real-time collaboration via WebSockets — see teammates' updates instantly
  • Role-based access control (Owner, Admin, Member, Viewer)
  • In-app team chat with message threads and file attachments
  • Task deadlines, priorities, assignees, and progress tracking
  • Project analytics dashboard with burndown charts and velocity metrics
  • GitHub integration — link tasks to commits and PRs
  • Dark / Light mode and fully responsive across all devices

Challenges Faced

  • Real-time drag-and-drop sync — ensuring the board state stayed consistent across multiple clients when tasks moved simultaneously. Used optimistic UI updates with server-side reconciliation.
  • Role-based access at the query level — preventing unauthorized users from accessing project data even through direct API calls. Implemented row-level security via Prisma middleware.
  • N+1 query problem — fetching tasks with their assignees triggered hundreds of queries. Fixed using Prisma's include with selective fields.

Future Improvements

  • AI assistant to auto-prioritize tasks and suggest sprint plans
  • Gantt chart view for timeline-based project planning
  • Slack and Discord webhook integrations
  • Time tracking with billable hours reporting for freelancers
  • Offline mode with conflict-free sync using CRDTs
