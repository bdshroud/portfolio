WeatherPulse
Real-Time Weather App

A beautiful, responsive weather application that delivers real-time forecasts, geolocation-based weather, animated sky backgrounds, and a 7-day outlook — all in an elegant, fast-loading interface.

Live Demo GitHub

Project Overview

WeatherPulse is a frontend-focused weather application that integrates with the OpenWeatherMap API to display real-time weather data. The UI dynamically changes its color scheme and background animation based on the current weather condition — sunny skies show a warm gradient, stormy weather triggers dark animated clouds.

I built this project to practice API integration, async JavaScript, geolocation, and responsive CSS animations — skills that are essential for modern frontend development.

Key Features

  • Auto-detects user location via Geolocation API for instant local weather
  • City search with debounced autocomplete suggestions
  • 7-day extended forecast with high/low temperatures and conditions
  • Hourly precipitation chart using Chart.js
  • Dynamic backgrounds and animated icons that match weather conditions
  • Wind speed, humidity, UV index, and "feels like" temperature
  • Toggle between Celsius and Fahrenheit
  • Offline caching with localStorage — last fetched data shown without internet

Challenges Faced

  • Geolocation permissions UX — browsers don't always grant location on first load. Implemented a graceful fallback to a default city with a clear prompt to enable location.
  • API rate limiting — the free OpenWeatherMap tier limits requests. Added localStorage caching with a 10-minute TTL to minimize API calls.
  • Smooth background transitions — changing the background based on weather without a jarring flash required CSS transition timing and class swapping strategies.

Future Improvements

  • Add weather alerts and severe weather notifications
  • Integrate air quality index (AQI) data
  • Add pollen count and allergy forecasts
  • Build a PWA version with push notifications for daily forecasts
  • Add interactive weather maps using Leaflet.js
